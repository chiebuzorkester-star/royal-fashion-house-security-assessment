Royal Fashion House – Website Security Assessment

1. Project Overview

This project documents an authorized website security assessment of Royal Fashion House.

The assessment forms part of my practical cybersecurity learning journey, focusing on website security, web application security and vulnerability assessment.

2. Project Objectives

* Understand website security assessment methodologies.
* Practise using OWASP ZAP.
* Explore HTTP requests and response headers.
* Understand common web application security risks.
* Document security observations and recommendations.

3. Tools Used

* OWASP ZAP (Zed Attack Proxy)
* Web browser
* HTTP/HTTPS fundamentals

4. Activities Performed

* Reviewed the publicly accessible website.
* Explored website navigation and functionality.
* Conducted an OWASP ZAP passive scan.
* Studied HTTP communication and security observations.

5. Learning Outcomes

This project strengthened my understanding of:

* Web application security.
* Passive vulnerability scanning.
* HTTP communication.
* Website security assessment fundamentals.

6. Project Scope

This was an authorized learning assessment conducted within the agreed testing scope.

The work was exploratory and does not represent a full penetration test or certification of the website’s security.

7. Future Improvements

* Document verified scan observations.
* Review relevant security headers.
* Develop evidence-based security recommendations.
* Expand practical web application security testing skills.
